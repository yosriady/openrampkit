# @openrampkit/server

Self-hosted OpenRampKit server: one web-standard handler for Cloudflare Workers, Next.js, Node, Bun and Deno.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/server
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/api/server.md
