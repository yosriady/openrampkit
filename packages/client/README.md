# @openrampkit/client

Framework-free OpenRampKit client and deposit/withdraw controller.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/client
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/api/client.md
