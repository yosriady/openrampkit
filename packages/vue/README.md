# @openrampkit/vue

Vue 3 wrapper for OpenRampKit: provider, Deposit and Withdraw buttons, composables. Safe for server rendering (Nuxt).

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/vue
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/api/vue.md
