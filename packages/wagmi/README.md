# @openrampkit/wagmi

wagmi wallet adapter for OpenRampKit.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/wagmi
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/wagmi.md
