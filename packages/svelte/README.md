# @openrampkit/svelte

Svelte wrapper for OpenRampKit: stores, actions and context helpers for Svelte 5 and 4. Safe for server rendering (SvelteKit).

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/svelte
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/api/svelte.md
