# @openrampkit/solid

Solid wrapper for OpenRampKit: provider, Deposit and Withdraw buttons, primitives. Safe for server rendering (SolidStart).

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/solid
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/api/solid.md
