# @openrampkit/web

<openramp-modal> web component (Lit, Shadow DOM) for deposits and withdrawals.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/web
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/api/web.md
