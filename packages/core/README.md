# @openrampkit/core

Types, exact money math, codes, region policy, flow table and pathway planner for OpenRampKit.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/core
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/api/core.md
