# @openrampkit/adapter-flashnet

OpenRampKit Flashnet Orchestra adapter (experimental): Cash App and Lightning onramp to USDC, and Bitcoin and Tron deposits.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-flashnet
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/flashnet.md
