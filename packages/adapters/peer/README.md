# @openrampkit/adapter-peer

OpenRampKit Peer (zkp2p) adapter for US P2P rails, opt-in.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-peer
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/peer.md
