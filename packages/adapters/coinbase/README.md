# @openrampkit/adapter-coinbase

OpenRampKit Coinbase Onramp adapter.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-coinbase
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/coinbase.md
