# @openrampkit/adapter-stripe-link

OpenRampKit adapter for the Stripe Link headless crypto onramp (Stripe calls it the Embedded Components onramp).

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-stripe-link
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/stripe-link.md
