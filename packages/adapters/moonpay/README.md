# @openrampkit/adapter-moonpay

OpenRampKit MoonPay adapter.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-moonpay
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/moonpay.md
