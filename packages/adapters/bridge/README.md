# @openrampkit/adapter-bridge

OpenRampKit Bridge adapter: virtual bank accounts (ACH, wire, SEPA, SPEI, Pix) that convert to stablecoins, and payouts from stablecoins to a bank account.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-bridge
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/bridge.md
