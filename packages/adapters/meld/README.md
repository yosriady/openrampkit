# @openrampkit/adapter-meld

OpenRampKit Meld aggregator adapter.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-meld
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/meld.md
