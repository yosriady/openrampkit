# @openrampkit/adapter-relay

OpenRampKit Relay adapter: wallet pay, transfer to deposit addresses, cross-chain hop.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-relay
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/relay.md
