# @openrampkit/adapter-kotani

OpenRampKit Kotani Pay adapter: M-Pesa, mobile money and bank checkout in Africa to USDC and USDT, and mobile money payouts.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-kotani
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/kotani.md
