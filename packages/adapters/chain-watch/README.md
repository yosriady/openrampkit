# @openrampkit/adapter-chain-watch

OpenRampKit chain-watch adapter: standing deposit addresses for the same token on the same chain. The deposit address is the destination itself, and the adapter watches the chain (ERC-20 Transfer logs on EVM chains, signatures on Solana). No provider account.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-chain-watch
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/chain-watch.md
