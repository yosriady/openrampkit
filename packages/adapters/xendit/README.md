# @openrampkit/adapter-xendit

OpenRampKit Xendit adapter: QRIS, QR Ph, PromptPay and e-wallets into your merchant account.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-xendit
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/xendit.md
