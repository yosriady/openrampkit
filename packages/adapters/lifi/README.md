# @openrampkit/adapter-lifi

OpenRampKit LI.FI adapter: pay from a wallet with any token on any chain (swap and bridge).

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-lifi
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/lifi.md
