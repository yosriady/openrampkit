# @openrampkit/adapter-paytrie

OpenRampKit PayTrie adapter (Interac e-Transfer in Canada).

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-paytrie
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/paytrie.md
