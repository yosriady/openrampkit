# @openrampkit/adapter-binance

OpenRampKit Binance adapter: deposit from a Binance account (Binance Pay Onchain on-ramp).

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/adapter-binance
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/adapters/binance.md
