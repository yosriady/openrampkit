# @openrampkit/react

React wrapper for OpenRampKit: provider, Deposit and Withdraw buttons, hooks.

Part of [OpenRampKit](https://github.com/yosriady/openrampkit): an open-source deposit and withdraw kit with a self-hosted server and pluggable adapters.

```bash
pnpm add @openrampkit/react
```

Docs: https://github.com/yosriady/openrampkit/tree/main/docs/api/react.md
