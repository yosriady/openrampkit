New framework wrappers over `@openrampkit/web`: `@openrampkit/vue` (Vue 3 and Nuxt), `@openrampkit/svelte` (Svelte 5 and 4, SvelteKit) and `@openrampkit/solid` (Solid and SolidStart). Each one has the same API shape as `@openrampkit/react` and is safe for server rendering.
